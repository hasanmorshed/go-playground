# Go Playground 🟢

Welcome to **Go Playground**, a comprehensive repository to learn **Golang** step by step. This repo is organized into three main levels:

1. **Beginners**
2. **Intermediate**
3. **Advanced**

---

## 📁 1. Beginners

The **Beginners** folder covers the foundational concepts of Go:

- **1. Variables** – Understanding variables in Go  
- **2. Constants** – Declaring constants  
- **3. Booleans** – Boolean data type and operations  
- **4. Numbers** – Working with integers and floats  
- **5. Strings** – String manipulation and operations  
- **6. Comparison Operators** – `==`, `!=`, `<`, `>` etc.  
- **7. Logical Operators** – `&&`, `||`, `!`  
- **8. Conditional Statement** – `if`, `else if`, `else`  
- **9. For Loop** – Basic loops in Go  
- **10. While Loop in Golang** – Using `for` like `while`  
- **11. Switch Statement** – Handling multiple conditions  
- **12. Arrays** – Fixed-size collections  
- **13. Slices** – Dynamic-size collections  
- **14. Iterating Over Slice** – Looping through slices  
- **15. Maps** – Key-value pairs  
- **16. Structs** – Custom data types  
- **17. Anonymous Structs** – Structs without a name  

---

## 📁 2. Intermediate

The **Intermediate** folder covers functions, scopes, pointers, and more advanced features:

- **Function** – Declaring and calling functions  
- **Function Expression** – Assigning functions to variables  
- **Anonymous Function** – Functions without names  
- **Methods** – Functions attached to structs  
- **Callback Function** – Passing functions as arguments  
- **Defer keyword** – Delaying execution until the function ends  
- **Scopes** – Variable visibility and lifetime  
- **Pointers** – Memory address manipulation  
- **Panic** – Error handling using `panic`  

---

## 📁 3. Advanced

The **Advanced** folder dives into concurrency and more complex concepts:

- **Interfaces** – Defining behavior without implementation  
- **Generics** – Writing type-safe reusable code  
- **Goroutines** – Lightweight concurrent functions  
- **Channels** – Communicating between goroutines  
- **WaitGroups** – Synchronizing multiple goroutines  
- **Select** – Handling multiple channel operations
